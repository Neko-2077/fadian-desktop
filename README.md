# 法典 — AI 数字法务助手（桌面版）

> 7 位 AI Agent 组成的数字法务团队，独立桌面应用。无需 EasyClaw，双击即用。

---

## 🎯 这是什么

一个独立的桌面软件。上传合同 → 7 个 AI Agent 接力审查 → 输出合规报告。

**完全独立运行**，不依赖 EasyClaw，只依赖 DeepSeek API。

---

## 📥 安装 & 运行

### 方式一：直接下载（推荐）

从 [Releases](../../releases) 下载 `法典-Setup.exe`，双击安装。

### 方式二：源码运行

```bash
# 1. 安装依赖
npm install

# 2. 启动
npm start
```

---

## 🔑 配置 API Key

1. 打开软件
2. 左侧面板 → 填入 DeepSeek API Key
3. 获取 Key：https://platform.deepseek.com/api_keys

一个 Key 即可驱动全部 7 个 AI Agent。

---

## ⚙️ 三种审查模式

| 模式 | 流程 | 适用场景 |
|------|------|---------|
| 🔍 标准合同审查 | 审查官 → 研究员 → 合规顾问 | 日常合同风险审查 |
| ✍️ 法律文书起草 | 研究员 → 起草员 → 审查官 | 生成律师函、法律意见书 |
| ⚖️ 完整案件准备 | 审查官 → 分析师 → 证据员 → 合规顾问 | 纠纷案件全面分析 |

---

## 🏛️ 团队角色

| 角色 | 职责 |
|------|------|
| ⚖️ 审查官 | 逐条标注风险等级 |
| 📚 研究员 | 检索法律法规依据 |
| 📋 合规顾问 | 整合输出合规报告 |
| ✍️ 起草员 | 起草法律文书 |
| ⚖️ 分析师 | 类案检索与判例分析 |
| 📎 证据员 | 证据链与时间线梳理 |

---

## 🛠 内核可修改

所有 Agent 的 System Prompt 在 `agents/` 目录下，直接编辑 `SOUL.md` 即可调整行为。

Pipeline 编排逻辑在 `pipeline-engine.js`，修改后重启即生效。
